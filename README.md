# TOEIC Speaking Audio Study

로컬에서 실행하는 토익스피킹 음성 학습 앱입니다. 사용자가 브라우저에서 음성 파일이나 폴더를 업로드하면 앱 안에 학습 라이브러리가 만들어집니다.

## 실행 방법

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 아래 명령을 실행합니다.

```bash
npm start
```

3. 브라우저에서 `http://localhost:4173`을 엽니다.

## 사용 방법

- `파일 추가`로 여러 음성 파일을 올릴 수 있습니다.
- `폴더 추가`로 폴더 안의 음성 파일을 한 번에 올릴 수 있습니다.
- 음성을 선택한 뒤 `편집` 탭에서 영어 스크립트를 붙여넣고 저장합니다.
- `단어 시간 자동 배치`를 누르면 음성 길이에 맞춰 단어 클릭 위치가 대략 배치됩니다.
- `내 녹음`에서 따라 읽은 녹음을 저장하고 다시 들을 수 있습니다.

## 저장되는 파일

- 업로드한 음성: `audio-library/`
- 스크립트와 즐겨찾기: `data/`
- 내 녹음: `recordings/`

이 폴더들은 개인 학습 데이터라서 기본적으로 Git에 올라가지 않도록 `.gitignore`에 포함되어 있습니다.

## 지원 음성 형식

`mp3`, `wav`, `m4a`, `aac`, `ogg`, `webm`, `flac`

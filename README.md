# TOEIC Speaking Audio Study

로컬에서 실행하는 토익스피킹 음성 학습 앱입니다. 사용자가 브라우저에서 음성 파일이나 폴더를 업로드하면 앱 안에 학습 라이브러리가 만들어집니다.

## 실행 방법

1. Node.js 18 이상과 Python 3.10 이상을 설치합니다.
2. 처음 한 번, 이 폴더에서 음성 인식 도구를 준비합니다.

Windows:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

macOS 또는 Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

3. 앱을 실행합니다.

```bash
npm start
```

4. 브라우저에서 `http://localhost:4173`을 엽니다.

## 사용 방법

- `파일 추가`로 여러 음성 파일을 올릴 수 있습니다.
- `폴더 추가`로 폴더 안의 음성 파일을 한 번에 올릴 수 있습니다.
- 업로드가 끝나면 영어 스크립트와 실제 단어별 시작 시간이 자동으로 추출됩니다.
- 화면에 대기, 모델 준비, 파일별 추출 개수와 완료 상태가 표시됩니다.
- 음성 파일 하나 또는 폴더 전체를 삭제할 수 있으며 관련 스크립트와 녹음도 함께 정리됩니다.
- 자동 추출된 문장은 `편집` 탭에서 직접 수정할 수 있습니다.
- `단어 시간 자동 배치`는 자동 추출이 어려운 파일을 수동으로 작성할 때 쓰는 보조 기능입니다.
- `내 녹음`에서 따라 읽은 녹음을 저장하고, 녹음별 영어 스크립트를 추출해 단어 단위로 다시 들을 수 있습니다.

처음 실행할 때는 영어 인식 모델을 내려받고 준비하므로 시간이 더 걸릴 수 있습니다. 이후 실행부터는 저장된 모델을 재사용합니다. 음성은 외부 서비스로 전송하지 않고 이 컴퓨터에서 처리됩니다.

## 저장되는 파일

- 업로드한 음성: `audio-library/`
- 스크립트와 즐겨찾기: `data/`
- 내 녹음: `recordings/`

이 폴더들은 개인 학습 데이터라서 기본적으로 Git에 올라가지 않도록 `.gitignore`에 포함되어 있습니다.

## 지원 음성 형식

`mp3`, `wav`, `m4a`, `aac`, `ogg`, `webm`, `flac`
